# Bear Bones JiuJitsu Website

Static website built with Next.js and deployed on Cloudflare Pages.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Shadcn/ui
- Cloudflare Pages

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

## Deployment

The site automatically deploys to Cloudflare Pages when changes are pushed to the main branch.
